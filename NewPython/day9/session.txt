⭐ What is a Session in Flask?

A session is a special dictionary stored on the client’s browser as a cookie, but protected using a secret key.

It is used to store temporary user data, for example:

login username

user id

shopping cart

theme mode

temporary preferences

✔ Data remains until browser closes or session is cleared
✔ Much safer than normal cookies (encrypted by Flask secret key)
🧪 Enable Session in Flask
from flask import Flask, session

app = Flask(__name__)
app.secret_key = "something-secret"


❗ secret_key is required — without it session won’t work.

⭐ Storing Data in Session
session["username"] = "vishal"
session["age"] = 21

⭐ Reading Data from Session
user = session.get("username")
print(user)

⭐ Removing one value
session.pop("username")

⭐ Clearing complete session
session.clear()

⭐ Example: Simple Login using Session
from flask import Flask, session, request, jsonify

app = Flask(__name__)
app.secret_key = "supersecretkey"


@app.post("/login")
def login():
    data = request.get_json()
    username = data.get("username")

    if not username:
        return {"error": "username required"}, 400

    session["user"] = username
    return {"message": "Logged in", "user": username}


@app.get("/profile")
def profile():
    user = session.get("user")
    if not user:
        return {"error": "Not logged in"}, 403

    return {"profile_of": user}


@app.get("/logout")
def logout():
    session.clear()
    return {"message": "Logged out"}

⭐ 1. Session Lifetime (Expiration Time)

By default, session lasts until the browser closes.

You can make it expire automatically:

from datetime import timedelta

app.permanent_session_lifetime = timedelta(minutes=10)


Mark session as permanent:

session.permanent = True


Now the session cookie expires after 10 minutes.

⭐ 2. Storing Complex Data (dict, list)

You can store any JSON-serializable data:

session["cart"] = ["apple", "banana", "milk"]
session["profile"] = {"name": "Vishal", "age": 21}


Reading:

cart = session.get("cart", [])
profile = session.get("profile", {})

⭐ 3. Sign vs Encrypt (important!)

Flask does NOT encrypt, it only signs session data.

Meaning:

Client cannot modify session

But client can see it (it is Base64 encoded)

⚠ Do NOT store:

passwords

tokens

bank data

⭐ 4. Server-Side Session Storage (Secure Alternative)

By default, session = client-side cookie.

To store session in server memory/DB, use Flask-Session:

pip install Flask-Session


Example:

from flask_session import Session

app.config["SESSION_TYPE"] = "filesystem"
Session(app)


Now session data is stored on server → safer.

⭐ 5. Delete Session Securely

Clear everything:

session.clear()


Delete one key safely:

session.pop("user", None)

⭐ 6. Session Protection for Login

Use in real login system:

if "user_id" not in session:
    return {"error": "Login required"}, 401

⭐ 7. Flash Messages use Session Internally

Flask flash system = session + signed messages.

⭐ 8. Check if session exists
if "user" in session:
    print("logged in")

⭐ 9. Regenerate session for security

If login happens:

session.clear()
session["user_id"] = db_user.id

⭐ 10. Session & Blueprint

Session works everywhere — no extra config needed.
